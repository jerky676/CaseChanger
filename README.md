# CaseChanger has moved

![CaseChanger Logo](images/logo.png)

**This repository and extension have migrated to a new home:**

## 👉 https://github.com/96daysleft/CaseChanger

The extension is now published under the **96daysleft** publisher. The previous
publisher (`jerky676`) is **deprecated** and will no longer receive updates.

## What you need to do

- **Users:** Uninstall the old extension and install "CaseChanger" by **96daysleft**
  from the VS Code Marketplace or Open VSX.
- **Contributors:** Update your git remote:

  ```sh
  git remote set-url origin https://github.com/96daysleft/CaseChanger.git
  ```

- Open issues and pull requests at
  [github.com/96daysleft/CaseChanger](https://github.com/96daysleft/CaseChanger).

All future development, releases, and documentation live at the new location.
